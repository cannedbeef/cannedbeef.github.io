how to request a game
  • if you have a github account, create a github issue on this site's repo (prefered)
  • alternatively, fill out this google form
how to add a game yourself
  • find an existing port or link to this game
  • assuming you have a github account, and know how too, create a pull request on this site's repo that adds this game to `gamedb.js`, as well as a thumbnail
