how to request a game
  • if you have a github account, create a github issue on this site's repo (prefered)
  • alternatively, fill out this google form
how to add a game yourself
  • find an existing port or link to this game
  • make sure it's either a *.github.io or *.gitlab.io link
    • alternatively, create a subdirectory in iframes/, in case you want to make changes to the game or code around it. if you do this, remember to set "external"=false
  • make sure it contains only the game, no extra ui or ads or anything
    • a tip for finding these links: most sites that host games have the game in an iframe with the ui around it, so use your browser's inspect tool to grab the raw link the iframme uses
  • assuming you have a github account, and know how too, create a pull request on this site's repo that adds this game to gamedb.js, as well as a thumbnail
    • just copy the entires for another game and change theme, hopefully it shouldn't be too hard to figure out how it works
  • remember to add any alternate links to the game that you can find
  • REMEMBER TO CREDIT THE CREATOR OF THE GAME, THE CREATOR OF THE WEB PORT, AND (if external,) THE OWNER OF THE LINKED REPO
